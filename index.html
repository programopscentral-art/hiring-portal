Connect a Google Sheet

Keep your hiring data in a Google Sheet — this dashboard fetches it on a schedule and re-renders automatically when you update the sheet.

Setup option 1 — Public sheet (simplest, ~5-min update lag)
  1. Click Download template above and import it into a new Google Sheet (File → Import → Upload → Replace spreadsheet).
  2. In Google Sheets: File → Share → Publish to web → Comma-separated values (.csv) → Publish. Copy the URL.
  3. Paste the URL above and click Connect. Or share the sheet as "Anyone with the link can view" and paste the regular share URL — that's near-real-time.
Setup option 2 — Private sheet via Apps Script proxy (recommended)

Keeps your sheet private. Real-time updates. The apps-script.gs file in this folder has the proxy code with full setup steps.

  1. Open your hiring Google Sheet → Extensions → Apps Script.
  2. Delete the placeholder code, paste the contents of apps-script.gs, and save.
  3. Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy.
  4. Authorize when prompted (Advanced → Go to script → Allow).
  5. Copy the Web app URL (ends with /exec) and paste it above. Click Connect.

Tip: To pull from a specific tab instead of the first one, append ?sheet=TabName to the /exec URL.

CSV format: single sheet with a Type column. Allowed types: Requirement, Filled, Pipeline.
Columns: Type, ID, Location, Role, Positions, Filled, Status, OpenedDate, TargetCloseDate, CandidateName, JoinDate, Source, Recruiter, Stage, AddedDate, RequirementID
Statuses: Open / In Progress / Filled / On Hold  •  Stages: Sourced / Screened / Interview / Offer / On Hold
Dates use YYYY-MM-DD. RequirementID on candidate rows links to a requirement (used to compute "in queue" per req).
Heads up: Google's published-to-web CSV is cached ~5 min — edits show up after that delay even if auto-refresh is faster. For real-time pulls from a private sheet, use the Apps Script proxy (see apps-script.gs in this folder).
